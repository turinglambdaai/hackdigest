# HackDigest 使用指南

[English](USER-GUIDE.md) · **简体中文**

通过按需标题翻译、文章摘要和讨论总结阅读 Hacker News。

## 当前可用状态

全部客户端功能可免费使用自己的模型密钥，模型费用另计。托管翻译尚未开放购买。

## 平台与安装

基于 Glaze 的 macOS、Windows、Linux 桌面预览。三平台默认原生 transport——HTTP 保留为显式开发适配器（`HACKDIGEST_TRANSPORT=http`）——发行 CI 对每个平台执行打包原生自检。密钥存储一致性仍在跟进（#2）。

从[官方 Releases](https://github.com/turinglambdaai/hackdigest/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。预览构建可能没有系统发行者签名或公证；不要为安装而关闭系统安全保护。

## 第一次使用

1. 打开一个信息流，先阅读一条原文。
2. 需要翻译时，配置自己的兼容模型端点和密钥，先测试一条标题。
3. 生成一份文章或讨论摘要，对照原文，并检查服务商用量后再批量处理。

## 数据、备份与恢复

退出后备份本地设置、书签与应用数据目录。翻译缓存可能含文章和评论；在安全存储迁移通过验收前，设置中可能含密钥。同步或分享备份前先检查内容。

## 联网、密钥与隐私

信息流和搜索会访问 HN 与搜索服务。翻译和摘要会把请求处理的标题、文章或评论发送给配置的模型服务商。AI 摘要可能遗漏背景或出错，应打开原始来源核对。

## 已知限制

密钥安全存储（模型 API key 进系统安全存储）仍在 #2 跟进；迁移落地前设置中仍可能含密钥。不包含移动端或托管同步服务。

## 更新与卸载

先备份数据，再阅读目标版本说明。应用内检查更新不一定能安装当前渠道的更新；按手册区分便携包、系统安装器和源码安装。不要绕过失败的验签或用来源不明的文件覆盖程序。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

## 获得帮助

在 [GitHub Issues](https://github.com/turinglambdaai/hackdigest/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
