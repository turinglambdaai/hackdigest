🚀 五分钟上手

下载、打开、配 Key、读第一篇。四步。

  1. 安装。到 Releases 页下载最新版。macOS：打开 .dmg，把 HackDigest 拖进「应用程序」；便携党直接用 .zip。Windows：双击 .msi 安装，或把便携 .zip 解压到任意目录。Linux：安装 .deb / .rpm，跑 .AppImage，或解压 .tar.gz。
  2. 首次启动。macOS 构建为 ad-hoc 签名：右键 → 打开（仅第一次）。Windows SmartScreen 可能告警：点「更多信息」→「仍要运行」。Linux 需要 libwebkit2gtk-4.1（发行版源里有）。
  3. 选语言。打开 设置 → 外观 → 界面语言，选「中文」或 English。界面语言与翻译目标语言相互独立（翻译目标见下方「阅读偏好」）。
  4. 配 API Key。不配 Key，翻译不工作。到 设置 → AI，选一个引擎，粘贴 Key，保存。手把手见下方「填 API Key」。
  5. 读第一篇。首页即 HN 信息流，标题已自动翻译。按 j/k 移动选中，Enter 打开帖子；详情页按 t 翻译本帖，Shift+T 翻译全部评论，d 生成 AI 摘要。按 ? 随时呼出速查表。

⚙️ 选翻译引擎

翻译、摘要都走一个 OpenAI 兼容端点。在 设置 → AI → 提供商 里选。

  • HackDigest Pro（托管）—— 免配置免 Key，开箱即用；每设备 7 天免费试用，之后需要 License Key。适合「只想能用」。
  • 国产直连—— 智谱 GLM（含 GLM Coding Plan 专属端点）、DeepSeek、通义千问、Kimi。国内网络可达，注册即有额度。适合大多数国内用户。
  • OpenAI / Ollama（本地）/ 自定义—— 有国际卡用 OpenAI；要完全离线用 Ollama（http://localhost:11434）；其他任意 OpenAI 兼容服务选「自定义」并填 Base URL。

切换引擎随时生效，已缓存翻译不受影响。同一帖子的翻译绝不重复计费 —— 换引擎只影响之后的翻译。

🔑 填 API Key

  1. 拿 Key。去所选平台的控制台创建 API Key：智谱 open.bigmodel.cn、DeepSeek platform.deepseek.com、阿里云百炼（通义）、Moonshot 平台（Kimi）。Ollama 本地运行，无需 Key。
  2. 填 Key。设置 → AI → 提供商选对应厂商 → 粘贴 Key → 选模型（不确定就选列表第一项）→ 保存。
  3. 验证。回到任意帖子按 t，几秒内出翻译即成功。
Key 只存在本机后端，页面（webview）拿不到 —— 设置页里已保存的 Key 只显示掩码。请求直达你所选的服务商，不经过任何中间方。

常见卡点

  • 报 401 —— Key 填错或已过期，重新生成一个。
  • 报 429 / 余额不足 —— 去平台充值或换模型；后端已内置限流重试。
  • Ollama 连不上 —— 确认本地服务在跑：ollama serve，并已 ollama pull 过模型。

☕ 三层 Digest

  • 文章 TL;DR—— 详情页按 d：五千词英文压成几段中文，先知道值不值得读。
  • 评论区观点提炼—— 同一个 d：八百条回复提炼成正反论点与社区倾向。配合 Shift+T 先通读翻译，再读提炼。
  • 每日晨报—— 侧栏「今日晨报」（或按 6）：今早首页两分钟读完，按主题分组。

摘要按次调用所选引擎，长文消耗相应 token；托管版走全局共享缓存，命中即免费。

📖 阅读偏好

都在 设置 → 外观：

  • 深浅色。跟随系统 / 浅色 / 深色三选一。
  • 字号。90% – 125% 四档。
  • 翻译目标语言。简体中文 / 繁体中文 / 日本語 / 한국어 / English。
  • 自动翻译。「标题自动翻译」默认开；「滚动自动翻译评论」默认关，手动按 Shift+T 更省 token。
  • 收藏。任意位置按 s 收藏，侧栏随时回看。

⌨️ 键盘快捷键

应用内按 ? 呼出速查表；默认值：

  • 列表：j/k 移动 · Enter/o 打开 · s 收藏 · t 翻译标题 · r 刷新 · 1–6 切换信息流 · / 搜索
  • 详情：←/u 返回 · t 翻译本帖 · Shift+T 翻译全部评论 · d AI 摘要

💾 数据存哪？

全部本地数据（设置、收藏、翻译缓存）放在一个目录：

  • macOS：~/Library/Application Support/hackdigest
  • Windows：%APPDATA%\hackdigest
  • Linux：~/.config/hackdigest

翻译缓存也在这里 —— 同一帖子只翻译一次，换设备不迁移缓存（重新翻译即可，成本极低）。

🔒 隐私

  • 无账号、无遥测。BYOK 模式下，翻译请求从本机直达你选的服务商。
  • API Key 只存本机后端，webview 拿不到，也不上传。
  • HN 数据来自官方 API 与 Algolia 搜索，不爬虫、不落地到我们的服务器。
  • 只有 Pro 托管模式经我们的服务器转发，并使用全局共享翻译缓存（帖子级缓存，不含个人信息）。

👤 要注册账号吗？

不用。BYOK 全功能免费，永远不需要账号。只有用 Pro 托管服务（免 Key 开箱即用）才涉及授权：每设备 7 天免费试用，之后购买终身 / 年度 License Key 填入即可，依旧没有账号体系。

🖥️ 平台支持

  • macOS —— Apple Silicon 与 Intel 双架构，.dmg 安装版 + .zip 便携版。
  • Windows —— Windows 10/11 x64，.msi 安装版 + .zip 便携版。
  • Linux —— x64 与 arm64 双架构，.tar.gz / .deb / .rpm / .AppImage / .zip 五种格式；需系统 WebKitGTK 4.1。
  • 移动端—— iOS / iPadOS / Android 在路线图（Phase 3），尚未开始。

🔄 更新

v0.3.0 起内置应用内更新：启动时拉取 Ed25519 签名清单，确认有新版后按安装方式处理 ——

  • 便携安装（macOS .zip / Windows .zip）—— 应用内一键原地换装，自动重启。
  • Linux—— 应用下载归档并打开所在文件夹，把解压内容覆盖到应用目录（归档安装的家族规则）。
  • 安装器安装（.dmg / .msi / .deb / .rpm）—— 应用带你到 Releases 页，下载新安装包覆盖安装（此类安装无提权无法自我改写）。

手动检查：设置 → 关于 → 检查更新。数据目录跨版本通用，更新不丢收藏与设置。

0.2.x 存量用户

应用内更新机制自 0.1.0 就已内置 —— 直接打开 设置 → 关于 → 检查更新，即可升到最新版。若你停在更早版本或检查失败，到 Releases 页下载安装包覆盖安装即可，数据目录不变。

🗑️ 卸载

  1. 删应用。macOS 把 HackDigest 移进废纸篓；Windows 在「设置 → 应用」卸载（MSI）或直接删便携目录；Linux sudo apt remove hackdigest（或对应包管理器）/ 删解压目录。
  2. 删数据（可选）。想清掉收藏与缓存，再删除上方「数据存哪」里的目录。API Key 随之删除。
